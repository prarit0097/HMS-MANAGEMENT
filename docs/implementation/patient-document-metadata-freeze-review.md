**Important catalogue correction:** the pattern in `DocumentMetadataCreate.filename`, `DocumentMetadataWithdraw.reason` and `DocumentMetadataIntent.filename` excludes the UTF16 surrogate range wholesale. In ordinary ECMAScript regex execution this rejects valid supplementary scalars represented by surrogate pairs, contrary to B1's explicit acceptance of valid pairs. The same patterns omit forbidden bidi controls U+061C/U+200E/U+200F. Remove the blanket surrogate-code-unit exclusion from the portable pattern (retaining explicit scalar/unpaired-surrogate enforcement in server validation and prose), or supply a tested paired-surrogate-aware equivalent; add the three missing bidi controls. This is a catalogue correction, not a change to B1's scalar rule.
