## Service-facing interfaces to freeze

All following names are proposed exact B2a interfaces; independent review may amend before freeze. No function accepts caller actor IDs or a `trusted=True` bypass.

- `capture_document_context(request: HttpRequest, operation: str) -> DocumentContext` in `document_authority.py`; operations exactly `intent.list`, `intent.detail`, `intent.create`, `intent.withdraw`. Raw Django request only; future DRF adapter unwraps after ordinary authentication/CSRF. Ambient transactions are rejected before DB reads here too. Capture performs the preliminary unlocked read-only active-session/global-action conjunction check; admit rechecks that preflight before detailed validation, then uses the locked authority sampler inside phase A. Preliminary membership reads are samples, not a lock against later staff changes.
- `sample_document_authority(context: DocumentContext, operation: str) -> DocumentAuthoritySample` in the same module; requires an already open owned phase with actor User locked as below. Revalidates mint/live binding/persisted session/identity and returns detached scalar expiry plus immutable branch-grant sets, never model/queryset/session data. No patient authority is implied by a global conjunction.
- `sample_document_network(context: DocumentContext, now: datetime) -> DocumentNetworkSample`; detached environment and coherent stored policy graph, no locks or maintenance. Internal policy mappings are copied and made immutable; no mutable snapshot dictionary escapes.
- `validate_document_selection(context, authority_sample, network_sample, selected_at: datetime) -> None`; pure check over those samples, expiry/clock/environment/IP/network semantics below. Any later DB wait/read requires resampling before a new selected_at. B2b must add exact patient-branch scope rechecks; this helper alone cannot authorise disclosure.
- `admit_document_command(context: DocumentContext, patient_id: str, *, document_id: str | None = None, key: str | None = None, body: bytes | None = None, query_pairs: list | tuple = ()) -> DocumentAdmission` in `document_access.py`. Operation comes from the mint. Detail requires document ID; create requires key/body; withdraw requires document ID/key/body; list accepts query pairs. Reject extraneous operation inputs. Reuse B1 canonical_uuid/parse_list_query/parse_create/parse_withdraw/command_fingerprint unchanged. Keys use canonical_uuid (there is no separate B1 key helper): invalid/missing command key maps400. Invalid patient/document path UUID maps concealed not_found404 after authentication/global action and consumes no allowance, matching the parent contract. No callback lets callers insert work inside admission.

`DocumentContext` is frozen, minted process-private, with actor_id, SHA256 session-key digest, originally captured epoch (`int>=0` or legacy None), operation, captured remote_addr/forwarded_for, verified_ip, environment_digest, aware operation_started_at and monotonic_started_at. All remote_addr/forwarded_for/verified_ip/session-digest/proof fields use repr=False; nested authority/network/admission objects must likewise suppress sensitive descriptor representations. Private request reference/mint token excluded from repr/comparison; the request graph itself is live, not immutable. Raw session key/hash never enters a public field/repr/error/event/log. Direct dataclass construction/foreign mint/operation mismatch fail closed. Trusted Python holding secrets is not sandboxed by this token. Future MCP/job adapters need a separately reviewed authenticator at the same permission ceiling.

`DocumentAdmission` is frozen and contains only context binding, operation, canonical patient/document/key scalars, recursively immutable normalized payload/query values, fingerprint where applicable, admitted_at and the original work-budget start. It is not a patient authority token or success response, may not skip phase-B checks, and is minted only after definite admission commit and enabled check. `DocumentServiceError(code, status, message, retry_after=None)` exposes fixed parent-contract-safe strings only; map B1 errors without echo. ## Exact read-only authentication/context rules

Supported configuration is `django.contrib.sessions.backends.db` with genuine configured `SessionStore`, existing key and default `django.contrib.auth.backends.ModelBackend` only. Require installed/configured backend path exactly; do not dynamically accept arbitrary configured backends. Unsupported engine/backend fails503 as unsupported service configuration; absent/malformed/expired authentication fails401. No session creation, rotation, save, flush or expiry extension. Do not call `auth.get_user(request)`, `identity_security.session_hash`, `lock_identity`, `require_platform` or network management authority helpers.

At mint and every authority sample:

1. Require raw HttpRequest and correct SessionStore/key; obtain fresh existing Session row by key without row lock/cache. Decode its signed data through installed store semantics, using Django's configured signing fallback keys. Require valid aware expiry strictly later than sampled time. B3 must supply an already-resolved authenticated actor; inspect raw request state without forcing AuthenticationMiddleware's unresolved SimpleLazyObject. Reject unresolved lazy actor401 rather than triggering `auth.get_user` indirectly. Even an already-resolved actor/cache is only a binding comparison, never authentication proof.
2. Require `_auth_user_id`, `_auth_user_backend`, `_auth_user_hash`; convert ID using the installed User PK conversion, obtain current active user through the pinned ModelBackend's `get_user`. Validate stored hash with Django constant-time comparison against fresh `get_session_auth_hash()` or configured `get_session_auth_fallback_hash()` values. Fallback acceptance remains read-only: no cycle_key/flush, even on invalid hash. Malformed/decode-failed/partial MFA-challenge-only session denies401. No independent new recent-MFA rule for reception.
3. Require live request actor ID/session-key digest/epoch and persisted auth actor/epoch to match capture. Persisted and live epoch must each be `type(value) is int and value>=0`, or legacy missing None; bool/negative/string reject. Preserve originally captured epoch. Compare against existing IdentitySecurity.auth_epoch, or0 if no row. Legacy missing epoch passes only authoritative0. Never create IdentitySecurity on reads; no overwrite from locked state. Current fresh User active is mandatory.
4. Phase samples retain persisted expiry; final pure check rejects `selected_at >= expiry`. Fresh user/password hash or epoch changes visible under actor locking deny. Ordinary other-request session deletion/update committed before final fresh sample denies; a mutation after that sample may coexist with an already selected result. Same-request flush/binding mutation denies. No instant cross-request logout cancellation or no-result-after-logout-ack promise. No session lock/global logout change/unbounded reread loop.

Global action authority is the intersection of current active Membership branch sets for every required permission: list/detail require `patients.read` AND `documents.registration.read`; create/withdraw additionally require `patients.write` AND `documents.registration.write`. All must coexist at one branch; a global union across branches is insufficient. Read current DB grants, never trust CurrentUser cache. ## Committed admission algorithm and error precedence

Successful admission supported only PostgreSQL>=17. SQLite may verify portable model/pure tests, never fake locks/timeouts with a permissive service fallback. Before any read, reject `connection.in_atomic_block` OR `autocommit=False` with503; use outermost `atomic(durable=True)` and transactional tests, not TestCase's nesting exemption. Capture start once; cooperative total5s budget spans capture/admission and future B2b phase, checked around blocking stages/encoding/exits. It cannot interrupt synchronous COMMIT or promise HTTP acknowledgement.

1. Validate mint/operation and current authenticated global same-branch conjunction before detailed scalar errors. Pure B1 input validation precedes allowance consumption. Reject malformed runtime flag (`type(setting) is not bool`)503 before admission; startup uses existing env_boolean accepted0/1/true/false normalization, default false, malformed env startup failure. Check pre-admission environment AND durable network allow. No patient lookup.
2. Start owned phase A. Immediately `SET LOCAL lock_timeout='2s'`, `statement_timeout='3s'`, `transaction_timeout='5s'` before row locks; no global settings. Lock actor User `select_for_update(no_key=True, of=('self',))`, then existing IdentitySecurity if present, then limiter row. Revalidate authenticated current epoch/session/global conjunction after waits. User lock serialises supported first profile creation and first limiter creation; unique PK is backstop. Do not upgrade User to full FOR UPDATE: staff changes insert target-user FK KEY SHARE while holding org gate. No Membership, StaffAccessRevision, org, Patient, Branch, Bed, network operator/owner or joined relation locks in phase A.
3. Fresh server UTC `now` after limiter wait; reject backward wall time before operation start or saved window_start503. Floor now to UTC minute. Missing row creates count1; same minute count<60 increments; at exactly next minute or later reset start/count1. Count60=>429 with ceil(window_end-now), clamped1..60; no row growth/write. Fixed-minute rule permits60 just before boundary plus60 just after. No sliding-window claim.
4. Force all deferred constraints with `SET CONSTRAINTS ALL IMMEDIATE` after limiter write. Then freshly sample session/identity/global grants and one coherent network graph; choose final admitted_at after waits. Pure final expiry/time/network/flag-type checks. No writes after constraints. A limit decision uses its post-lock `now`; if the final pass crosses a minute boundary it remains conservatively charged to that sampled minute, not refreshed through a second write/retry loop. No later claim that window_started_at equals floor(admitted_at).
5. Exit phase A successfully, check cooperative budget. If the typed flag is false, raise503 OUTSIDE atomic: valid disabled attempt retains its committed increment. Return admission only when flag remains true; later disable is rechecked before B2b patient lookup. A malformed override/dependency/final authority/network failure before commit rolls back the tentative increment. Any failure after known commit retains it. Do not refund on B2b404/409/429/503 or replay.

Catch DB exceptions after atomic exit. Definite rollback=>503/no admission. Unknown commit acknowledgement=>503/no admission when driver returns; discard suspect connection, never assert rollback/refund or retry automatically. Later explicit retry consumes its own allowance; B2b keyed receipt reconciliation remains separate. A blocked synchronous driver cannot promise prompt503. No connection transfer to another thread/monkeypatch retry loop.

| Condition, in processing order | Result | Committed increment |
|---|---|---|
| Ambient transaction/unsupported configuration/dependency |503|None guaranteed|
| Unauthenticated/stale/malformed session |401|No|
| No global same-branch conjunction |403 before target/input detail|No|
| Pure invalid command / oversized body / malformed path |400 /413 /concealed404|No|
| Malformed flag or unavailable network; valid network deny |503 or generic403|No|
| Saturated actor after fresh locked checks |429|No new increment|
| Valid flag=false, otherwise admissible |503 after phase-A commit, no patient lookup|Yes|
| Flag=true and phase-A known commit |Internal admission result only|Yes|
| Final check/constraint/time failure before phase-A commit |401/403/503 as above|No|
| Commit acknowledgement uncertain |503/no result/discard connection|Unknown, never refunded|
| Future B2b inaccessible target after global action |Concealed404; creator-only403 only after visible scope|Retained|

## Final network/time semantics

Recompute environment_snapshot and normalise captured socket/header using explicitly trusted proxies. Compare digest and verified IP with mint: environment/IP drift or unavailable/corrupt graph=>503; valid environment/selected-overlay denial=>generic403. The captured IP is no bypass; untrusted forwarding cannot replace the socket. Do not use earlier network_decision.effective_policy across a blocking SELECT.

Load existing validated NetworkSnapshot once per final sample. Preserve confirmed/candidate/pending graph; pure selector uses confirmed with no pending, candidate only `activated_at <= selected_at < rollback_at`, confirmed at/after exact rollback even `expired_unreconciled`. Before activation/backward clock=>503. No reconciliation/mutation/operator locks. Existing loader's pre-read clock may conservatively reject a newly activated graph newer than that clock; no retry to stretch budget.

The guarantee is the latest materialised statement snapshot plus pure deadline projection. Policy deny visible before that SELECT denies; policy commit after the statement snapshot can coexist with the sampled result, including the small interval before selected_at. Session expiry is evaluated at selection; concurrent logout is sampled as above. B2b must resample after its event/FK/constraint waits and select its own final time before detached audited projection. Phase-A sample is never permission to skip that. No instantaneous network/session revocation claim and no extra owner/org lock.
